# 小说连载工坊 (novel-studio)

纯 Python 标准库的本地 GUI 应用（零第三方依赖，不受 Smart App Control 影响），
把「AI 写短篇连载」的完整流程固化为 8 个步骤页面，对接本地离线大模型
（Ollama / LM Studio 等 OpenAI 兼容 API）。

## 启动

1. 先启动本地大模型服务，任选其一：
   - Ollama：默认 `http://127.0.0.1:11434/v1`（模型如 `qwen2.5:14b`）
   - LM Studio：默认 `http://127.0.0.1:1234/v1`（需开启 Local Server）
2. 双击 `start.bat`，或命令行 `python novel_writer_studio.py`。

## 功能概览

八步流程（对应 8 个标签页）：

设置与项目 → 范文提炼文风 → 范文拆解仿写 → 人物档案 → 人物关系 → 剧情大纲 → 章节摘要 → 章节正文

核心闭环——「范文 → 完整项目 → 仿写」：

```
范文 txt ──AI 分段通读──> 完整项目（文风/人物/关系/大纲 + 逐章摘要 + 原文按章归档）
        ──(可选)仿写设定──> 第 7 页逐章 AI 生成正文 ──> 仿写小说 ──> 导出全文 md
```

其他要点：

- 生成正文默认只带本章出场人物（按摘要中出现的姓名裁剪档案，避免全量灌入稀释注意力），可取消
- 流式输出：生成过程逐块显示，可随时中止并保留已生成部分
- 切换章节/Tab 时有未保存修改会弹确认，不会静默丢失

## 目录结构

```
novel_writer_studio.py   # 主程序（GUI + 全部逻辑）
projects/<项目名>/       # 每个小说一个项目目录（materials + chapters/）
start.bat                # 启动入口
```
